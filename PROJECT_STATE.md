## Сделано (код)
- Пациенты: список/поиск/архив, создание, профиль (общая информация, анамнез с автосохранением и голосом, консультации, история). E2E (Playwright/Chromium): вход, создание пациента, автосохранение, сохранение после перезагрузки — проходят.
- Автосохранение: движок `createSaver` (debounce, подтверждение сервером, офлайн-повтор, конфликты) + 7 юнит-тестов.
- Слой данных `Db`/`Storage` (local + Supabase), авторизация, proxy, страница входа, оболочка приложения, схемы Zod (карта, пациент, настройки), форматирование цен.

## Блокеры / допущения
- Нет credentials Supabase → демо-режим на локальном адаптере (ADR-001). Для боевого режима нужны `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`, `SUPABASE_SERVICE_ROLE_KEY`; миграции в `supabase/migrations`.
- Фирменные изображения придётся извлечь из референсов (PDF.js) и проверить чистоту; иначе запросить оригиналы.
