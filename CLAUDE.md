# KRIS SKIN — инструкции проекта

Закрытое веб-приложение косметолога: пациент → анамнез → консультация → карта пациента (10 страниц) → утверждение → PDF в фирменном дизайне → отправка пациенту.
Цель: оформление карты за 5–15 минут вместо нескольких часов.

**В начале каждой сессии читай:** `CLAUDE.md`, `PROJECT_STATE.md`, `DECISIONS.md`. После каждого этапа обновляй `PROJECT_STATE.md` / `CHANGELOG.md` и коммить.

## Стек
Next.js (App Router, версия новее обучающих данных — перед кодом читай `node_modules/next/dist/docs/`, см. `AGENTS.md`; `middleware` → `proxy.ts`), TypeScript strict, Tailwind v4, shadcn/ui, lucide-react, Supabase (Postgres/Auth/Storage), `@react-pdf/renderer`, Zod, Vercel. Только бесплатные сервисы и библиотеки.

## Архитектура
- `src/lib/db/` — абстракция данных `Db` + `Storage`. Две реализации: `supabase` (прод, RLS) и `local` (демо без Supabase, файлы в `.data/`, gitignored). Выбор по env в `src/lib/db/index.ts`. Весь доменный код работает только через интерфейс.
- `src/lib/auth/` — вход по email/паролю (Supabase Auth либо локальная scrypt-авторизация с подписанной cookie), `proxy.ts` защищает маршруты.
- `src/lib/schemas/` — Zod-схемы: пациент, анамнез, данные карты (JSONB), настройки. Серверная валидация обязательна.
- `src/pdf/` — **единый** PDF-рендерер (`CardDocument`), страницы-шаблоны, шрифты, дизайн-токены. Предпросмотр, скачивание, шаринг и сохранённый файл используют один и тот же рендерер и одни и те же данные (`CardSnapshot`).
- `src/app/(app)/` — защищённые разделы; `src/app/login` — вход.
- `supabase/migrations/` — SQL-миграции, `supabase/seed.sql` — вымышленные данные.
- `scripts/` — dev-инструменты (рендер PDF в PNG для визуального сравнения).

## Жёсткие правила
1. **Не назначать, не диагностировать, не генерировать медицинские рекомендации.** Все решения принимает и утверждает специалист. Единственное применение ИИ — исправление орфографии и пунктуации надиктованного текста (см. «Голос и редактор»): без изменения чисел, названий и назначений.
2. Медицинские поля: «Да / Нет / Неизвестно / Не указано». Никогда не подставлять «нет» автоматически.
3. Утверждённые карты и PDF **неизменяемы**: snapshot + сохранённый файл. Изменение каталога, шаблона, настроек, фото не затрагивает старые документы. Повторное скачивание = сохранённый PDF.
4. Приватность: референсные PDF (`references/`), `.env*`, `.data/`, `assets-private/`, любые PDF и медданные — только в `.gitignore`. Никаких реальных ПДн в Git, демо, логах и документации. Во внешние API уходит только надиктованный текст для исправления (Anthropic, с согласия специалиста); данные пациента приложение туда не добавляет. Приватные Storage buckets, только подписанные временные ссылки.
5. Крупные файлы грузятся напрямую в Supabase Storage (signed upload URL), не через Vercel Functions.
6. Не хранить медданные в `localStorage` (только UI-предпочтения).
7. Нет заглушек в основном сценарии: каждая кнопка работает, метрики считаются из БД.
8. Не заявлять «отправлено», если файл не передан (Web Share API → fallback на скачивание).
9. Не заявлять «тест пройден», если он не запускался.

## Голос и редактор (P0)
`VoiceInput` у каждого текстового поля через `SpeechProvider` (Web Speech API; Whisper — позже). Предупреждение о передаче аудио (и текста в Claude, если задан ключ) при первом включении, аудио не хранится, есть отмена. В разделах карты с «Состояния кожи» текст пишется сразу и исправляется на месте (`src/lib/ai/correct.ts`, защита чисел `isSafeCorrection`, ADR-019); на обложке, в личных данных и вне карты — только после подтверждения. Режим «Надиктовать консультацию» — только явные названия разделов, без имитации ИИ. Рекомендации — блоки (заголовок, абзац, списки, таблица, изображение, примечание, индивидуальный). Экран карты: навигация · редактор · предпросмотр.

## Дизайн
Background `#F5F1ED`, Surface `#FFFFFF`, Primary `#791F2B`, Accent `#B99B86`, Text `#292524`, Muted `#8C8580`. Заголовки — Prata (serif), интерфейс — Manrope (оба OFL, кириллица, лежат в `public/fonts`, встраиваются в PDF). Русский интерфейс, mobile-first, PWA.

## PDF-референсы
Формат страницы 595×822 pt. 10 страниц: обложка, личные данные, состояние кожи, схема ухода, активы, питание, витамины и анализы, рекомендованные средства, план процедур, заключение. Три варианта обложки. Подробности композиций — в `DECISIONS.md` (ADR-006). Количество референсов в `references/` растёт — анализировать **все** PDF (`node scripts/render-pdf.mjs`).
